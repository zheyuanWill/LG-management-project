# 2026-08-17

## 生产部署包（阿里云 ECS 一键部署）
用户要"直接部署网站"→ 确认目标：**阿里云从零建 ECS + 自助一键脚本 + 先用公网IP走http（域名备案后再切HTTPS）**。
产出 `deploy/` 部署包（已通过 `docker compose -f docker-compose.prod.yml config` 校验）：

- `docker-compose.prod.yml`（项目根）：代码烤进镜像（无 --reload / 无源码挂载），仅 caddy(80/443)+minio(9000) 暴露；单 Caddy 入口 `/api/*`→backend:8000，其余→frontend:80；挂载 `scripts/init.sql`（启用 pgvector）；数据库表由后端 `init_db()` 自动建。
- `deploy/Caddyfile`：支持 `SITE_ADDRESS` 环境变量（`:80`=http，域名=自动HTTPS）。
- `deploy/.env.prod.example`：密钥用 `__GENERATE__`、MinIO 公开地址用 `__AUTO__` 占位。
- `deploy/bootstrap.sh`（在 ECS 上跑）：装 Docker（阿里云镜像源）+ 配 Docker Hub 镜像加速器（daocloud/163/阿里云）+ 生成随机密钥 + 探测 ECS 公网IP 填 `MINIO_PUBLIC_ENDPOINT` + 构建启动。
- `deploy/deploy-to-ecs.sh`（本机跑）：tar 打包（排除 node_modules/.git/.env 等）scp 到 ECS 并触发 bootstrap。
- `deploy/README.md` + `deploy/阿里云部署指南.md`（控制台建机步骤 + HTTPS 升级 + MinIO 混合内容处理）。

关键坑已处理：Docker Hub 国内拉镜像需镜像加速器；前端同源 `/api/v1` 无需构建时配地址；MinIO 预签名 URL 需公网可达（暴露 9000）；生产密钥随机强口令。

下次若要真部署：用户需在阿里云建 ECS（Alibaba Cloud Linux 3，放行 22/80/443/9000，配置 SSH 密钥），再本机执行 `LG_SSH_KEY=~/.ssh/x.pem bash deploy/deploy-to-ecs.sh <公网IP>`。
